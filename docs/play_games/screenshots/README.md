# Play Store 휴대전화 스크린샷

이미지 규격: **1920 × 1080 PNG**, 16:9, 각 8MB 이하.

| 순서 | 파일 | 내용 |
|---|---|---|
| 1 | `01_fronts.png` | 20개 전선과 난이도 선택 |
| 2 | `02_gameplay.png` | 콤보·보스전·자동 공격 |
| 3 | `03_levelup.png` | 레벨업 강화 선택 |
| 4 | `04_boss.png` | 최종 보스전 |
| 5 | `05_evolution.png` | 진화 무기 플레이 |
| 6 | `06_friends.png` | 달베어 친구 5명 |

## 업로드

Play Console → **기본 스토어 등록정보 → 휴대전화 스크린샷**에서 2~8장을 올립니다. 프로모션을 사용하려면 4장 이상을 1080px 이상으로 올리는 것이 좋습니다. 위 6장을 순서대로 올리면 됩니다.

전체 압축 파일: `screenshots_1920.zip`

## 참고

- 스크린샷에 상태 표시줄이나 알림이 없는 게임 화면만 사용했습니다.
- 1280 × 720 원본을 16:9 비율 그대로 1920 × 1080으로 확대했습니다.
- 태블릿용은 별도로 필요하지 않다면 비워도 됩니다.
