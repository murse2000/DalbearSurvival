# Play Games Services 속성 업로드 자료

Play Console의 **Play Games 서비스 → 설정 및 관리 → 구성 → 속성**에서 아래 파일을 사용합니다.

| 항목 | 파일 | 규격 |
|---|---|---|
| 게임 프로젝트 설명 | `description_ko.txt` | UTF-8 텍스트 |
| 게임 프로젝트 아이콘 | `icon_512.png` | 512 × 512 PNG, RGB, 불투명 |
| 게임 프로젝트 그래픽 이미지 | `feature_1024x500.png` | 1024 × 500 PNG, RGB, 불투명 |

## 업로드 순서

1. Play Console에서 **속성 → 세부정보 수정**을 엽니다.
2. **설명**에 `description_ko.txt` 내용을 붙여넣고 저장합니다.
3. **아이콘**에 `icon_512.png`를 업로드합니다.
4. **그래픽 이미지**에 `feature_1024x500.png`를 업로드합니다.
5. **저장** 후 속성의 세 항목이 모두 **확인 필요**에서 벗어났는지 확인합니다.
6. Play Games Services 설정 변경 사항을 **게시**합니다.

## 참고

- Play Games Services의 설명은 Google Play 스토어 등록정보의 설명과 일치시키는 것이 좋습니다.
- 아이콘은 휴대폰에서 원형으로 잘릴 수 있으므로 중앙의 달베어가 잘리지 않게 유지했습니다.
- 그래픽 이미지는 Android 타이틀 화면을 1024 × 500으로 잘라 만들었습니다.
- 이미지에 투명 영역이 없도록 RGB PNG로 저장했습니다.
